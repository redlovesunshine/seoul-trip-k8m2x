首爾行程書：GitHub Pages 上傳步驟

1. 登入 GitHub，右上角 + → New repository。
   Repository name 取一個不好猜的名字，例如 seoul-trip-k8m2x。
   選 Public（免費帳號的 Pages 需要公開），按 Create repository。
2. 在新 repo 頁面點 uploading an existing file。
3. 把這個資料夾裡的全部內容拖進去：index.html、manifest.webmanifest、sw.js、icons 資料夾、img 資料夾。
   （電腦版 Chrome／Safari 可以直接拖整個資料夾；手機不建議。）
4. 按 Commit changes。
5. 進 Settings → Pages。Source 選 Deploy from a branch，Branch 選 main、資料夾選 /(root)，按 Save。
6. 等 1–2 分鐘，頁面上方會出現網址：https://你的帳號.github.io/repo名稱/
7. 把網址傳給旅伴，用 iPhone Safari 開啟 → 分享 → 加入主畫面。

更新內容：回到 repo，點 index.html → 鉛筆圖示編輯，或重新上傳覆蓋，Commit 後 1–2 分鐘生效。
